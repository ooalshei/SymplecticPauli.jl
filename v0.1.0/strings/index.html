Pauli strings

Building one

A single Pauli string is a UPauli — a bit pattern with no phase — or a Pauli, which carries one of $1, -1, i, -i$ alongside it. Either can be written as text, as indices, or as the raw bits:

using SymplecticPauli

UPauli("XY-Z")           # 'X', 'Y', 'Z' and '-' (or 'I'), leftmost qubit first
Pauli{UInt64}(XY-Z)
UPauli([2, 3, 1, 4])     # 1-4 for I, X, Y, Z
Pauli{UInt64}(XY-Z)
UPauli(UInt(0xa3), 4)    # the bits, plus the number of qubits they describe
Pauli{UInt64}(XY-Z)

The three are the same string. Reading it back is tostring:

tostring(UPauli("XY-Z"))
"XY-Z"

The leftmost character is qubit 1, and it is the lowest bit of each half — so "X-" is 0b0001 and "-X" is 0b0010, while "Z-" is 0b0100:

[tostring(UPauli(UInt(b), 2)) => string(b, base = 2, pad = 4) for b in 0x0:0xf]
16-element Vector{Pair{String, String}}:
 "--" => "0000"
 "X-" => "0001"
 "-X" => "0010"
 "XX" => "0011"
 "Z-" => "0100"
 "Y-" => "0101"
 "ZX" => "0110"
 "YX" => "0111"
 "-Z" => "1000"

 "-Y" => "1010"
 "XY" => "1011"

Storage

The integer the bits live in is a type parameter, and so is the number of qubits: a UPauli{UInt16,4} is a four-qubit string held in a UInt16. Since a string needs two bits per qubit, UInt covers 32 qubits and UInt128 covers 64. Ask for more than the type can hold and you get an error rather than silent truncation:

UPauli{UInt16}("XY-Z")
Pauli{UInt16}(XY-Z)
julia> UPauli{UInt8}("XXXXX")
ERROR: ArgumentError: String length cannot exceed 4. Consider using a larger unsigned integer type.

Both types are isbitstype, so a string costs no allocation and an array of them is a flat block of memory.

The phase

UPauli deliberately has no phase: it is a bit pattern, and two of them multiply by ⊻. The phase appears the moment you ask what operator the pattern is. The convention is the one that makes each string Hermitian, $i^{\#Y}$:

Pauli(UPauli("Y")).sign, Pauli(UPauli("YY")).sign, Pauli(UPauli("XZ")).sign
(0 + 1im, -1 + 0im, 1 + 0im)

so that tomatrix of any string squares to the identity and equals its own adjoint:

m = tomatrix(Pauli("Y"))
2×2 Matrix{Complex{Int8}}:
 0+0im  0-1im
 0+1im  0+0im

A Pauli tracks its phase exactly through products, and prints it in front of the string. Note that the printed phase is relative to the Hermitian convention, so a plain "Y" shows as (+):

Pauli("Y"), Pauli("Y", -1), UPauli("X") * UPauli("Y")
(Pauli{UInt64}((+)Y), Pauli{UInt64}((i)Y), Pauli{UInt64}((i)Z))

Multiplying by a scalar gives a Pauli too, which means the scalar has to be a fourth root of unity — for anything else, use a one-term PauliSentence:

-1 * UPauli("Y-")
Pauli{UInt64}((-)Y-)

Products and commutation

Every combination of UPauli and Pauli multiplies, and the result is a Pauli:

UPauli("XX") * UPauli("ZZ")
Pauli{UInt64}((-)YY)

Dropping the phase — the bit pattern alone — is ⊻:

tostring(UPauli("XX") ⊻ UPauli("ZZ"))
"YY"

com answers the question that actually comes up in an algebra: do these two commute, and what is their product? Both fall out of the same handful of bit operations, so asking for one gives the other for free:

com(UPauli("XX"), UPauli("ZZ")), com(UPauli("X-"), UPauli("Z-"))
(Pair{UPauli{<:Unsigned, 2}, Bool}(Pauli{UInt64}(YY), true), Pair{UPauli{<:Unsigned, 2}, Bool}(Pauli{UInt64}(Y-), false))

A commutator is then two lines with no matrices in sight: $[P, Q] = 0$ when they commute, and $2PQ$ when they do not.

Counting

countx, county, countz and counti are popcounts on the two halves. A Y sets both bits of its qubit, so it is counted by countx and countz as well as by county:

p = UPauli("XY-Z")
countx(p), county(p), countz(p), counti(p)
(2, 1, 2, 1)

counti is the odd one out: it folds the two halves together first, so a Y counts as one non-identity qubit like any other factor, and the result is the number of identity factors the printed string shows. Q - counti(p) is the weight of the string — the number of qubits it acts on — so sorting by counti orders strings from the identity outwards.

Lists of strings

A PauliList is an ordered list of strings on the same number of qubits: a generating set, an algebra, a subalgebra. It is an AbstractVector of the raw bit patterns, with the qubit count stored once for the whole list:

v = PauliList(["XX-", "-YZ", "Z-Z"])
3-element PauliList{UInt64, 3}:
 0x0000000000000003
 0x0000000000000032
 0x0000000000000028
length(v), v.qubits, eltype(v)
(3, 3, UInt64)

The whole Base vector vocabulary works, and slices come back as PauliLists:

push!(v, UPauli("YYY").string)
tostring(v[2:end])
3-element Vector{String}:
 "-YZ"
 "Z-Z"
 "YYY"

Elements are bare integers, so wrap one to treat it as a string on its own:

UPauli(v[1], v.qubits)
Pauli{UInt64}(XX-)

That is the trade the type makes: a million strings is a million integers, not a million objects, and the qubit count is not repeated a million times.
