SymplecticPauli.jl

Pauli operators as symplectic bit strings — products, commutators and rotations at the cost of a few machine instructions.

A Pauli string on $Q$ qubits is one unsigned integer of $2Q$ bits. The low $Q$ bits say which qubits carry an $X$ factor, the high $Q$ bits which carry a $Z$, and a qubit with both bits set carries a $Y$:

\[P = P_1 \otimes \cdots \otimes P_Q \;\longleftrightarrow\; (z \,|\, x), \qquad (z_j, x_j) = (0,0),\,(0,1),\,(1,0),\,(1,1) \;\text{ for } P_j = I, X, Z, Y .\]

Everything else follows from that. The product of two strings is an exclusive or,

\[PQ \;\propto\; (z_P \oplus z_Q \,|\, x_P \oplus x_Q),\]

its phase is $(-1)^{z_P \cdot x_Q}$ times a power of $i$ counting the $Y$s, and the two strings commute exactly when the symplectic form

\[\langle P, Q \rangle = z_P \cdot x_Q + x_P \cdot z_Q\]

is even. A product is one xor; a commutation test is two ands, an xor and a popcount. No matrix is ever built — tomatrix exists for checking small cases, and that is all it is for.

Installation

The package is not registered:

using Pkg
Pkg.add(url="https://github.com/ooalshei/SymplecticPauli.jl")

Quick start

julia> using SymplecticPauli

julia> p, q = UPauli("XY-Z"), UPauli("Z--Z")
(Pauli{UInt64}(XY-Z), Pauli{UInt64}(Z--Z))

julia> p * q                          # a product, and the phase it picks up
Pauli{UInt64}((-i)YY--)

julia> com(p, q).second               # the same string, plus: do they commute?
false

An operator is a PauliSentence — strings with coefficients:

julia> H = PauliSentence(["ZZ-", "-ZZ", "X--", "-X-", "--X"], [1.0, 1.0, 0.5, 0.5, 0.5]);

julia> length(H), H.qubits
(5, 3)

julia> trace(H)
0.0

and rotating it by $e^{i\theta A}$ is ad, which touches only the terms that anticommute with the generator:

julia> rotated = ad(H, UPauli("Y--"), pi / 4, atol = 1e-12);

julia> tostring(rotated)["Z--"]       # X-- has been turned into Z--
0.5 + 0.0im

What is in the box

UPaulione string, bits only
Paulione string with a phase $\pm 1, \pm i$
PauliListan ordered list of strings — a generating set, an algebra
PauliSentencestrings with coefficients — an operator
comcommutation test, returning the product string with it
ad, ad!conjugation by $\prod_j e^{i\theta_j A_j}$
tracetrace of an operator, without the matrix
countx, county, countz, countibit counts on a string
tostring, tomatrixtext and dense matrix, for reading and checking

*, +, -, ^ and cis come from Base and are extended to all of these.
